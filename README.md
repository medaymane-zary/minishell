# Description

The goal from this project is to implement a minimal shell that mimics bash behavior.

The minishell supports redirection, pipes and parentheses.
It has some built-in commands and can execute any binary following the PATH variable.

# Instructions

* compile the project using `make`.
* execute the minishell using `./minishell`.
